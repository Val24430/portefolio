# Portfolio BTS SIO — Template

Ce dépôt contient un portfolio professionnel, moderne et responsive conçu pour un étudiant en BTS SIO.

Fichiers importants
- `index.php` : page principale du portfolio (remplacez les placeholders).
- `style.css` : styles en thème sombre, responsive et animations.
- `scripts.js` : navigation mobile, smooth reveal et logique de formulaire (placeholder).
- `assets/` : images et `CV-[PRENOM]-[NOM].pdf` (remplacez par votre vrai CV).

Personnalisation rapide
1. Ouvrez `index.php` et remplacez les placeholders `[PRÉNOM]`, `[NOM]`, `[PROJET]`, `[ENTREPRISE]`, etc.
2. Remplacez `assets/profile.svg` par votre photo (ou `profile.jpg`) en gardant le même nom.
3. Remplacez `assets/CV-[PRENOM]-[NOM].pdf` par votre CV en PDF.
4. Pour activer un vrai envoi de formulaire, remplacez la logique dans `scripts.js` par un appel à une API ou un service de formulaire (Formspree, Netlify Forms, backend PHP, etc.).

Accessibilité & SEO
- Les sections sont sémantiques et le menu est accessible via clavier.
- Ajoutez du contenu réel, des titres optimisés et des meta descriptions pour améliorer le SEO.

Déploiement
- Ouvrez `index.php` dans un serveur local PHP ou déposez sur un hébergeur qui supporte PHP (ou renommez en `index.html` si vous n'utilisez pas PHP).
